# Asset handling and distribution

MW3 (2011) game binaries, media and engine code are proprietary. The existence of a legal local PC installation does not necessarily grant redistribution or source translation rights. Keep game files outside Git. Do not place them into Actions logs, workflow artifacts, public releases or hosted webpages.

Local inspection is separate from redistribution. Native engine translation and shader conversion require a rights review, reliable provenance and implementation checks.

GitHub private repositories are not a substitute for software distribution permission. A browser builder that uploads three files must explicitly identify and restrict what those files contain. Do not upload protected engine binaries or original game asset archives without verifying permission.

The game folder at C:\Program Files (x86)\Call of Duty Modern Warfare 3 was located and inspected only at top level; no original game files have been copied into this scaffold.
